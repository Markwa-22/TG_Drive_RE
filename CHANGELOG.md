# Исправления от 22.04.2026

## 🐛 Исправленные ошибки

### 1. Ошибка авторизации: "The API key is required for new authorizations"

**Проблема:**
- API ключи (api_id и api_hash) не передавались в клиент Pyrogram
- Клиент создавался без параметров авторизации

**Исправление:**
- Обновлена функция `starting()` в `main.py`
- Теперь API ключи читаются из `config.ini` и передаются в клиент
- Добавлена проверка наличия ключей перед созданием клиента

**Файл:** `main.py:258-298`

```python
# Было:
app = Client("TelegramCloud", phone_number=phone)

# Стало:
app = Client("TelegramCloud", api_id=api_id, api_hash=api_hash, phone_number=phone)
```

---

### 2. Ошибка загрузки файлов: "'NoneType' object has no attribute 'is_premium'"

**Проблема:**
- После `app.start()` объект `app.me` был равен `None`
- Pyrogram не загружал информацию о пользователе автоматически
- При попытке загрузить файл происходила ошибка

**Исправление:**
- Добавлен принудительный вызов `app.get_me()` после `app.start()`
- Это гарантирует загрузку информации о пользователе
- Теперь `app.me.is_premium` доступен для проверки лимитов

**Файл:** `main.py:289-295`

```python
app.start()

# Ensure client has loaded user info
if app.me is None:
    try:
        app.get_me()
    except:
        pass
```

---

### 3. Предупреждения deprecation для asyncio

**Проблема:**
- Предупреждения о устаревших методах asyncio в Python 3.16
- `asyncio.WindowsSelectorEventLoopPolicy` deprecated
- `asyncio.set_event_loop_policy` deprecated

**Исправление:**
- Обновлен код инициализации asyncio
- Используется `ProactorEventLoop` для Windows
- Добавлен фильтр для подавления всех deprecation warnings

**Файл:** `main.py:1-20`

```python
# Suppress all deprecation warnings
warnings.filterwarnings('ignore', category=DeprecationWarning)

# Use ProactorEventLoop for better Windows compatibility
if sys.platform == 'win32':
    try:
        loop = asyncio.new_event_loop()
        asyncio.set_event_loop(loop)
    except RuntimeError:
        pass
```
