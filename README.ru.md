# TG Drive RE — Telegram Cloud (Remastered)

Десктопный клиент, который превращает **чат с Telegram-ботом в личное облако**:
папки, загрузка и скачивание файлов, упаковка больших файлов в многотомные 7-Zip
архивы, предпросмотр картинок — всё в современном веб-интерфейсе (Eel + Pyrogram)
с тёмной и светлой темой.

Форк [SuperZombi/Telegram_Cloud](https://github.com/SuperZombi/Telegram_Cloud)
с переработанным интерфейсом и приведённой в порядок структурой проекта.

> 🇬🇧 English version: **[README.md](README.md)**

---

## ✨ Возможности

- **Дерево папок внутри Telegram** — весь индекс хранилища лежит в одном файле
  `path.bd`; ни сервера, ни отдельной базы данных.
- **Загрузка**: одиночные файлы, целая папка или сразу несколько объектов.
- **Скачивание**: один файл («Сохранить как…»), целая папка или **пакет выделенных
  файлов** в выбранную один раз папку.
- **Многотомные архивы**: файлы больше лимита Telegram режутся 7-Zip на тома и
  собираются обратно при скачивании.
- **Определение Telegram Premium** — лимит 4 ГБ (тома по 3.9 ГБ) вместо 2 ГБ / 1.9 ГБ.
- **Работа с файлами**: поиск, сортировка (по имени / дате), переименование,
  перемещение в другую папку, удаление (одиночное, пакетное и «удалить пустые папки»).
- **Предпросмотр картинок** с генерацией миниатюр (можно выключить для скорости загрузки).
- **Тёмная / светлая тема** и **русский / английский** интерфейс.
- **Оптимизированный загрузчик** — адаптивные чанки (64 КБ – 512 КБ) и автоматические
  повторы при FloodWait.
- **Современный интерфейс** этого форка: каркас из шапки, сайдбара, содержимого и
  статус-бара, **сайдбар с изменяемой шириной** и списком корневых папок, пилюля
  занятого места, счётчик выделенных файлов и **значки типа записи** у названия:
  📁 — загруженная папка, 📦 — многотомный архив.

## 🚀 Установка и запуск

**В Windows самое простое** — запустить **`install.bat`** двойным щелчком: он поставит все
зависимости (по желанию — в изолированную папку `.venv`) и проверит 7-Zip, предложив
поставить его через `winget install 7zip.7zip`. Дальше запуск — `start.bat`.

**Вручную:**

```bash
git clone https://github.com/<ваш-аккаунт>/<ваш-форк>.git
cd <ваш-форк>
python -m venv .venv                                  # необязательно, но удобно
.venv\Scripts\python -m pip install -r requirements.txt
```

Батники для Windows:

| Файл | Что делает |
|---|---|
| `install.bat` | ставит/обновляет зависимости (можно в `.venv`) и проверяет 7-Zip |
| `start.bat` | обычный запуск |
| `start_with_check.bat` | сначала проверяет Python, зависимости и 7-Zip |
| `help.bat` | интерактивное меню (запуск / тест / сброс / установка) |
| `test_connection.bat` | показывает аккаунт, статус Premium и лимиты загрузки |
| `reset_settings.bat` | удаляет `config.ini`, `TelegramCloud.session`, `settings.json` |

Либо вручную: `python main.py`. Любой батник предпочитает `.venv`, если эта папка есть,
и иначе работает с системным Python — оба варианта совместимы. Папка `.venv` указана в
`.gitignore` и никогда не публикуется.

### Первый запуск

1. Окно входа спросит **номер телефона**, **api_id** и **api_hash**.
2. Введите код, который придёт в Telegram.
3. Рядом с `main.py` появятся `config.ini` и `TelegramCloud.session` — **не публикуйте их**.

## 🗂 Структура проекта

```
Telegram Cloud/
├── main.py                    # точка входа: Eel-приложение + логика Telegram
├── scripts/                   # python-модули (main.py добавляет папку в sys.path)
│   ├── archiver.py            # 7-Zip: упаковка, разбиение, распаковка
│   ├── pyrogram_optimizer.py  # адаптивные чанки + FloodWait (используется main.py)
│   ├── premium_detector.py    # определение Premium
│   ├── upload_manager.py      # высокоуровневый API загрузки (опционально)
│   ├── optimized_uploader.py  # загрузчик на Telethon (опционально, по умолчанию не используется)
│   ├── database.py            # хранилище на SQLite (опционально, в приложение не включено)
│   ├── migrate_to_sqlite.py   # миграция path.bd → SQLite (опционально)
│   ├── encryption.py          # опционально, в приложение не включено
│   └── test_auth.py           # проверка подключения для test_connection.bat
├── Web/                       # веб-интерфейс: HTML / CSS / JS / иконки
├── docs/prototype.html        # отдельный прототип интерфейса, по которому делался редизайн
├── requirements.txt
├── settings.json.example      # шаблон settings.json
└── *.bat                      # ярлыки запуска для Windows
```

`main.py` намеренно остаётся в корне: это точка входа, и она ищет `config.ini`,
`path.bd` и файл сессии рядом с собой; папку `scripts/` он добавляет в `sys.path`,
чтобы импорты модулей работали как раньше.

## 📦 Как хранятся папки и архивы

В Telegram всё — это **файл, отправленный в чат с ботом**, включая то, что выглядит
как папка:

| Что загружаете | Как лежит в Telegram | Как выглядит в списке |
|---|---|---|
| папку | архив (многотомный, если большая) | иконка папки + значок 📁 |
| папку больше лимита | многотомный архив | иконка папки + значки 📦 📁 |
| большой файл больше лимита | многотомный архив | иконка архива + значок 📦 |
| обычный файл / архив | сам файл | иконка архива или типа, без значков |
| папку, созданную в программе | просто путь в `path.bd` | иконка папки, без значков |

Поэтому у архива может стоять значок папки: это действительно папка с диска,
упакованная для перевозки.

## ⛔ Что НЕЛЬЗЯ заливать в общий доступ

Эти файлы уже перечислены в `.gitignore` — перед первым `git push` проверьте `git status`:

| Файл / папка | Почему нельзя публиковать |
|---|---|
| `config.ini` | ваши **api_id / api_hash** и номер телефона |
| `TelegramCloud.session` | **сессия Telegram** — полный доступ к аккаунту |
| `path.bd` | индекс хранилища: все пути и `message_id` ваших файлов |
| `tgdrive.db` | тот же индекс в формате SQLite (если включите) |
| `settings.json` | личные настройки |
| `Temp/`, `Saves/` | временные архивы и превью — могут содержать ваши файлы |
| `Web.backup_pre_redesign/` | локальный бэкап старого интерфейса |
| `__pycache__/`, `.venv/` | служебные файлы |

Если файл сессии всё-таки утёк: Telegram → **Настройки → Устройства** → завершите
эту сессию и удалите файл на диске.

## 🛠 Решение проблем

- **«API key is required for new authorizations»** — запустите `reset_settings.bat`,
  откройте программу заново и введите ключи с <https://my.telegram.org>.
- **Не грузится файл больше 2 ГБ** — для разбиения нужен 7-Zip; проверьте через
  `start_with_check.bat`.
- **«7-Zip не найден»** — установите (`winget install 7zip.7zip`) или положите
  `7z.exe` в папку `tools/` рядом с `main.py`.
- **Цикл входа / странное состояние сессии** — `reset_settings.bat`, затем `start.bat`.
- Подробнее: **TROUBLESHOOTING.md**.
